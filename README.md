## 🚀 Key Features

- **Minimalist Clean Landing Page**: Pure modern typography with zero boxed rectangles, elegant visual breathing room, and an artistic hand-drawn brush stroke CTA.
- **Continuous Left-Aligned Cyber Face Background**: 300-frame progressive canvas animation running at 30 FPS with an invisible organic edge dissolve into deep space.
- **Cinematic AI Workspace Banner**: 300-frame 16:9 ultra-smooth canvas video showing high-tech AI laboratory environments with interactive 3D perspective tilt and specular lighting.
- **Interactive 3D Model Avatar**: Sticky character viewport scrubbed dynamically on scroll via sub-pixel delta lerping.
- **Executive Command Console**: Clean HUD telemetry chips, target roles, and instant ATS/printable resume downloads.
- **Featured Projects**:
  - Multimodal Lung Cancer Prognosis (CT Imaging & Clinical Biomarkers)
  - Multimodal Emotion Recognition (Vision, Audio & Text Fusion)
  - Financial Sentiment Analysis (RoBERTa & LoRA Transformers)
  - Autonomous Parking Slot Detector (YOLOv8 Edge Vision)

## 🛠️ Tech Stack

- **Frontend**: Modern Vanilla HTML5, CSS3, JavaScript (ES6+), Canvas 2D API
- **Fonts**: Space Grotesk, Plus Jakarta Sans, JetBrains Mono
- **Audio Engine**: Synthesized Web Audio API interface SFX
- **Hosting**: GitHub Pages (100% static, zero backend dependencies)

## 💻 Local Development

Clone the repository and run any local static server:

```bash
# Option 1: Python
python -m http.server 3000

# Option 2: Node.js
node server.js
```

Then open `http://localhost:3000/` in your browser.
